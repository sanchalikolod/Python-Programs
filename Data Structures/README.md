# Python Data Structures

This folder contains programs and practice problems based on Python's built-in data structures.

## 📚 Topics Covered

* **Lists**

  * Creating and accessing lists
  * Adding and removing elements
  * List operations
  * Searching and sorting
  * List traversal

* **Tuples**

  * Creating and accessing tuples
  * Tuple operations
  * Tuple unpacking
  * Converting between lists and tuples

* **Sets**

  * Creating sets
  * Adding and removing elements
  * Union, intersection and difference
  * Removing duplicate elements

* **Dictionaries**

  * Creating and accessing dictionaries
  * Adding, updating and deleting key-value pairs
  * Traversing dictionaries
  * Counting frequencies using dictionaries
  * Dictionary-based problems



Learning and practicing Python data structures.
